## 3. 防超卖验证

压测后执行以下 SQL 验证：

```sql
-- 1. 库存不为负
SELECT id, available_seats, total_seats FROM movie_schedule WHERE available_seats < 0;
-- 预期: 0 行

-- 2. 同场次同座位不重复
SELECT schedule_id, row_num, col_num, COUNT(*) c
FROM seat_lock WHERE status = 2
GROUP BY schedule_id, row_num, col_num HAVING c > 1;
-- 预期: 0 行

-- 3. 订单数 = 已售座位数
SELECT s.id, s.available_seats, s.total_seats,
       s.total_seats - s.available_seats AS sold,
       (SELECT COUNT(*) FROM ticket_order o WHERE o.schedule_id = s.id AND o.status = 1) AS paid_orders
FROM movie_schedule s WHERE s.id = 1;
-- 预期: sold = paid_orders
```

## 4. 压测执行方法

```bash
# 1. 启动完整演示环境
bash deploy/scripts/start-demo.sh

# 2. 重置专用压测场次
bash tests/performance/reset.sh --yes

# 3. 执行场景
bash tests/performance/run.sh read
bash tests/performance/run.sh unique
bash tests/performance/run.sh contention
bash tests/performance/run.sh batch
bash tests/performance/run.sh rate-limit

# 4. 校验一致性
bash tests/performance/verify.sh
```
